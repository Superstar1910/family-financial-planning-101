# Contributing

Contributions should improve clarity, accessibility, factual accuracy or localisation without promoting a financial product.

1. Open an issue describing the problem and jurisdiction.
2. Support material factual claims with a primary or authoritative source.
3. Add or update the source register.
4. Preserve the educational—not advisory—boundary.
5. Run `npm run check`, `npm test` and `npm run build`.
6. Confirm keyboard, mobile and print usability.

Never submit personal household financial data, credentials or account identifiers.
