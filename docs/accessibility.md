# Accessibility statement

The site targets WCAG 2.2 AA. It uses semantic landmarks, heading order, a skip link, keyboard-operable tabs and forms, visible focus, labelled inputs, live calculator outputs, high-contrast colours, reduced-motion support, SVG text alternatives and responsive layouts.

The worksheets are designed for A4 printing. JavaScript enhances calculators and the diagnostic; the educational content and worksheets remain available without it.

## Manual review checklist

- Navigate the full page using only Tab, Shift+Tab, Enter and Space.
- Confirm focus is always visible.
- Check form labels and output announcements with a screen reader.
- Zoom to 200% and inspect at 320 CSS pixels.
- Print to A4 and inspect table clipping and page breaks.
- Recheck contrast after any colour change.
