# Publication governance

## Ownership

- Content owner: Kenneth Legesi / designated financial-literacy editor
- Technical owner: Repository maintainer
- Jurisdiction reviewer: Appointed qualified Uganda reviewer

## Cycle

- Quarterly: links, regulator names, disclaimers and issue log
- Annually: full sources, curriculum, calculations, accessibility and localisation review
- Immediate: material regulatory, tax, deposit-protection, pension, provider-status or consumer-warning change

## Versioning

Use semantic versions. Patch releases correct language, links or defects without changing the teaching model. Minor releases add backwards-compatible modules. Major releases materially change the framework, data model or public interpretation.

Every published change requires a changelog entry, test results and reviewer acknowledgement. Do not silently overwrite historical facts or citations.
